Чтобы номер версии в заголовке страницы (h1) и в легенде формы сам увеличивался при коммите с index.html, один раз в клоне репозитория выполните:

  git config core.hooksPath .githooks

После этого при каждом коммите, куда входит изменённый index.html, хук pre-commit увеличит число во всех вхождениях <span class="form-version">vN</span> и снова проиндексирует файл.

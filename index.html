Умножение многочленов и то же самое через «длинное» целое v5

Коэффициенты задаются от младшей степени к старшей: a₀; a₁; a₂ … (между ними — только ;, в числе — только цифры и точка) для a₀ + a₁x + a₂x² + …. Вещественные коэффициенты округляются до n знаков после запятой, затем умножаются на 10ⁿ и превращаются в целые. Число P(B) = c₀ + c₁B + c₂B² + … при достаточно большом B (степень десяти) умножается как целое; коэффициенты произведения многочленов совпадают с «разрядами» разложения P(B)·Q(B) по степеням B — без переносов между разрядами.

Входные данные v5

Если включено, то запись aₙ; …; a₁; a₀ будет автоматически преобразована в a₀; a₁; …; aₙ. В полях коэффициентов и композиции допустимы только цифры, знаки +/-, точка (десятичная) и ; между коэффициентами; запятая не используется.

Как парсится?

Поддерживается: + (сумма), * (умножение), ^ (целая степень). Пример: (P+Q)^3 + P*Q.

Описание логики парсинга
P/p и Q/q — это многочлены из двух полей коэффициентов выше.
* — умножение многочленов.
+ — сумма многочленов.
^ — возведение многочлена в целую степень (пример: P^4).
Приоритеты: ^ выше * выше +. Скобки ( ) поддерживаются.
Степень после ^ должна быть целым числом ≥ 0.

Графики коэффициентов (по индексам)

По оси X — только целые индексы коэффициентов: 0, 1, 2, … (те, которые реально есть в P, Q и P·Q).

Пояснение

«Нули между коэффициентами» здесь соответствуют выбору основания B = 10^L: каждый коэффициент (по модулю) помещается в L десятичных позиций с дополнением нулями, а значение P(B) вычисляется как ((…((cm)B + cm−1)B + … )B + c0) (схема Горнера). Подбирается минимальное L, при котором B = 10L строго больше модуля каждого коэффициента P, Q и произведения P·Q, чтобы при записи Σ ci Bi не было переносов между блоками и можно было однозначно прочитать коэффициенты результата по разрядам B.

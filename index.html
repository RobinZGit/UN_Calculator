Умножение многочленов и то же самое через «длинное» целое

Коэффициенты задаются от младшей степени к старшей: a₀; a₁; a₂ … для a₀ + a₁x + a₂x² + …. Вещественные коэффициенты округляются до n знаков после запятой, затем умножаются на 10ⁿ и превращаются в целые. Число P(B) = c₀ + c₁B + c₂B² + … при достаточно большом B (степень десяти) умножается как целое; коэффициенты произведения многочленов совпадают с «разрядами» разложения P(B)·Q(B) по степеням B — без переносов между разрядами.

Пояснение

«Нули между коэффициентами» здесь соответствуют выбору основания B = 10^L: каждый коэффициент (по модулю) помещается в L десятичных позиций с дополнением нулями, а значение P(B) вычисляется как ((…((cm)B + cm−1)B + … )B + c0) (схема Горнера). Подбирается минимальное L, при котором B = 10L строго больше модуля каждого коэффициента P, Q и произведения P·Q, чтобы при записи Σ ci Bi не было переносов между блоками и можно было однозначно прочитать коэффициенты результата по разрядам B.
